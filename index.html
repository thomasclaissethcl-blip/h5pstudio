Données de l'activité

Mode avancé pour les contenus dont les champs ne sont pas encore disponibles dans l’édition guidée. Les modifications faites ici peuvent aussi être prévisualisées.

Widget officiel H5PEditor.Text

Mode expérimental isolé

Premier essai avec le véritable widget de saisie de texte H5P. Il fonctionne uniquement sur les champs texte simples de la bibliothèque importée. Ce mode ne constitue pas encore l’éditeur H5P complet. Les autres champs et ressources restent inchangés.

Ouvrez un fichier H5P contenant un champ texte simple.

En cas d’erreur du composant officiel, le formulaire guidé et l’édition JSON restent disponibles.
